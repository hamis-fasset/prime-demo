by the agent toolchain, so this is a one-time manual step):

cp "../../../../../context/fasset-biz-design-system/assets/fonts/GeneralSans-Variable.woff2" .
cp "../../../../../context/fasset-biz-design-system/assets/fonts/GeistMono-Variable.woff2" .

(Run from this directory. Absolute source:
 Operating System/pm-os/products/prime/context/fasset-biz-design-system/assets/fonts/)

directly from the design-system bundle via a relative URL, so the prototype
still renders with the correct faces as long as the repo layout is intact.
